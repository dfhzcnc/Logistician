# Logistician

Logistician is a World of Warcraft addon that combines Auction House tools,
shopping and selling workflows, crafting planning, production queues, and
bills of materials.

## Installation

1. Download the ZIP from the latest GitHub release.
2. Extract the `!Logistician` folder into the applicable WoW client's
   `Interface/AddOns` directory.
3. Restart World of Warcraft or run `/reload` after updating addon files.

## Supported clients

The supported interface versions are declared in `!Logistician.toc`. Release
packages are built directly from the repository and retain the required
top-level `!Logistician` directory.
