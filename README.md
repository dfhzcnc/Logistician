<h1 align="center">Logistician</h1>

Logistician is a World of Warcraft economy and profession-planning addon. It
brings Auction House research, repeatable buying and selling workflows, and
crafting logistics together in one interface.

## Features

- **Auction House shopping:** Create reusable shopping lists, save recent
  searches, compare unit and stack prices, inspect available quantities, and
  review sellers before buying.
- **Efficient selling:** Browse auctionable inventory by category, select items
  directly from your bags, compare current listings, configure stack sizes and
  quantities, and post from a streamlined Selling tab.
- **Auction management:** Review active auctions, identify undercuts, and use a
  dedicated Cancelling workflow when prices change.
- **Market history:** Retain scan data by realm and faction to display price
  history, recent market observations, and longer-term pricing context.
- **Crafting logistics:** Plan production goals and queues, track required
  reagents, and build bills of materials that connect profession work with
  Auction House shopping.
- **Customizable workflow:** Configure search, selling, tooltip, shortcut, and
  display behavior to match the way you use the Auction House.

## Installation

1. Download the ZIP from the [latest GitHub release](https://github.com/dfhzcnc/Logistician/releases/latest).
2. Extract the `!Logistician` folder into the applicable WoW client's
   `Interface/AddOns` directory.
3. Restart World of Warcraft or run `/reload` after updating addon files.

## Supported clients

Supported interface versions are declared in `!Logistician.toc`. Release
packages are built directly from the repository and retain the required
top-level `!Logistician` directory.
