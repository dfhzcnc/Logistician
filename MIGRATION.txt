LOGISTICIAN DATA MIGRATION
==========================

Do this only while World of Warcraft is completely closed.
Keep backup copies of every file before renaming or editing it.

ACCOUNT-WIDE DATA
-----------------

In:
  _anniversary_\WTF\Account\<ACCOUNT>\SavedVariables\

Rename:
  !Auctionator.lua      -> !Logistician.lua
  !Auctionator.lua.bak  -> !Logistician.lua.bak

This restores the existing AUCTIONATOR_* tables without changing their schema,
including shopping lists, price/scan history, posting history, recent searches,
vendor cache, selling groups, and global auction configuration.

CHARACTER DATA
--------------

Each character has two legacy files in:
  _anniversary_\WTF\Account\<ACCOUNT>\<REALM>\<CHARACTER>\SavedVariables\

  !Auctionator.lua
    contains AUCTIONATOR_CHARACTER_CONFIG

  !WiderProfessions.lua
    contains WiderProfessions_DB and WiderProfessionsPlusDB

The new combined file is:
  !Logistician.lua

To preserve all three character tables, create !Logistician.lua by combining
the complete variable assignments from both old files. Do not rename one old
file over the other, because that would discard the other addon's character
data. Repeat for each character you want to migrate. Merge the .bak files the
same way only if you want a combined backup.

COMPATIBILITY
-------------

Logistician intentionally retains these established table names:
  AUCTIONATOR_CONFIG
  AUCTIONATOR_SAVEDVARS
  AUCTIONATOR_SHOPPING_LISTS
  AUCTIONATOR_PRICE_DATABASE
  AUCTIONATOR_POSTING_HISTORY
  AUCTIONATOR_VENDOR_PRICE_CACHE
  AUCTIONATOR_RECENT_SEARCHES
  AUCTIONATOR_SELLING_GROUPS
  AUCTIONATOR_CHARACTER_CONFIG
  WiderProfessions_DB
  WiderProfessionsPlusDB

Keeping these names is what makes a filename-only account migration possible
and avoids conversion risk for shopping lists and historical scan records.

ADDON FOLDERS
-------------

Enable only !Logistician after migrating. Disable or remove !Auctionator and
!WiderProfessions to prevent both the legacy and integrated copies from loading.
